# test-task-payment-service

## Requirements

- python 3.13
- uv (optional)
- docker

## Run

```shell
docker compose up -d --build
```

## Restart

```shell
docker compose up -d --build app
```

## Stop

```shell
docker compose down
```

## Run tests

```shell
make test
```

## Linter

```shell
make lint
```
